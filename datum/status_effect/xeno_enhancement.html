Vars

enhancement_activeTRUE once apply_enhancement() succeeded. Status effects get on_remove() called even if on_apply() failed, so this guards against reverting something that was never applied.
levelThe level of the mutation this effect belongs to. Set by the "/two" and "/three" subtypes.
xenomorph_ownerThe xenomorph that owns this status effect.

Procs

apply_enhancementApplies the effect of the current level. Must return TRUE on success. If it returns FALSE it must not have changed anything.

remove_enhancementReverts everything apply_enhancement() did. Only called after a successful apply_enhancement().
